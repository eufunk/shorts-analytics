Welche YouTube Shorts werden bis zum Ende angeschaut und warum?

shorts-analytics ist ein Research-Agent mit eigener Bedienoberfläche im Browser. Dort wählt man Themen und die Anzahl der Videos und startet den Lauf per Klick. Danach arbeitet der Agent ohne weiteres Zutun alle Schritte ab: Er sucht passende Shorts über die YouTube-Schnittstelle, prüft und bereinigt die Daten, lässt Thema und Einstieg jedes Videos von der KI einordnen, wertet alles statistisch aus und schreibt am Ende einen Report. Den Fortschritt verfolgt man live, kann den Lauf jederzeit anhalten und sieht sich anschließend die Ergebnisse direkt dort an.

„Welche Themen, Videoformate, Hooks und strukturellen Eigenschaften weisen bei erfolgreichen YouTube Shorts eine besonders hohe Zuschauerbindung bzw. Durchschauquote auf?“

Wofür wurde das Projekt erstellt?

Das Projekt verfolgt zwei Ziele: eine fachliche Fragestellung beantworten und dabei lernen, wie man einen vertrauenswürdigen KI-Agenten baut.

🎯

Fachliches Ziel

Herausfinden, welche Shorts Zuschauer nach den ersten Sekunden vom Weiterwischen abhalten und möglichst bis zum Ende gesehen werden. „Erfolg“ bedeutet hier nicht nur viele Aufrufe, sondern vor allem hohe Zuschauerbindung (Retention).

🧠

Lernziel

Verstehen und üben, wie man einen KI-Agenten baut, ohne unnötige Enterprise-Architektur. Er soll verständlich, modular, testbar und für eine einzelne Person handhabbar sein.

Welchen Nutzen hat es?

Statt Bauchgefühl und Einzelbeispielen liefert der Agent eine systematische, wiederholbare Auswertung.

⚙️

Automatisierte Recherche

Ein Befehl startet den ganzen Ablauf: Videos sammeln, bereinigen, einordnen, auswerten und einen Report schreiben.

🛡️

Keine erfundenen Daten

Jedes Datenfeld trägt seine Herkunft (public, own_analytics, derived, unavailable). Fehlende Werte werden als fehlend ausgewiesen und nicht geschätzt.

📐

Verlässliche Zahlen

Mittelwerte, Mediane, Quantile, Korrelationen und Rankings rechnet Python/pandas deterministisch. Das Sprachmodell rechnet nie.

🔁

Reproduzierbar

Jeder Lauf speichert Rohdaten, bereinigte Daten, Klassifizierungen, Suchparameter und das verwendete Modell.

📊

Bequeme Bedienoberfläche

Läufe per Klick starten und anhalten, den Fortschritt live verfolgen und Ergebnisse mit KPIs, Vergleichen nach Thema, Hook, Format und Länge sowie Rankings ansehen.

💡

Übertragbare Erkenntnisse

Der Report zeigt, welche Hooks, Formate und Längen sich auf eigene Shorts übertragen lassen.

Für wen ist das Projekt?

Für alle, die Kurzvideos datenbasiert verstehen wollen, und für alle, die lernen wollen, wie ein KI-Agent sauber aufgebaut wird.

🎬

Content Creator

Wer eigene Shorts produziert und wissen will, welche Einstiege, Themen und Längen Zuschauer halten.

📈

Social-Media- & Marketing-Teams

Wer Content-Strategien mit Daten statt mit Vermutungen begründen möchte.

🔬

Analyst:innen & Studierende

Wer eine methodisch transparente Untersuchung mit offen dokumentierten Grenzen braucht.

🧩

Einsteiger:innen in KI-Agenten

Wer an einem echten, verständlichen Beispiel lernen will, wann ein Sprachmodell sinnvoll ist und wann klassischer Code besser passt.

So funktioniert der Agent

Eine feste, nachvollziehbare Pipeline statt einer undurchsichtigen Multi-Agenten-Konstruktion. Das Sprachmodell (Claude) kommt nur dort zum Einsatz, wo inhaltliches Verständnis gebraucht wird.

  1. ResearchSuchparameter und Kategorien festlegen
    Python
  2. DatensammlungÖffentliche Daten über die YouTube Data API v3
    Python
  3. ValidierungPlausibilität und Vollständigkeit prüfen
    Python
  4. BereinigungDuplikate entfernen, Werte normalisieren
    Python
  5. KlassifizierungThema, Hook-Typ und Struktur je Video
    LLM
  6. Quantitative AnalyseMittelwerte, Mediane, Quantile, Korrelationen
    Python
  7. MustererkennungWiederkehrende Muster interpretieren
    LLM
  8. RankingThemen, Hooks und Formate vergleichen
    Python
  9. Reportreport.json und report.md, anzeigbar in der Oberfläche
    Python

    Evaluation-AgentEin eigener Prüfschritt gleicht jede Aussage im Report mit den Rohdaten ab.
  • ○
    Eigene YouTube-Analytics-Daten (Ebene 2)OAuth-Anbindung an die YouTube Analytics API, um echte Retention-Werte („stayed to watch“, gesehener Prozentsatz) für den eigenen Kanal einzubeziehen. Die Schnittstelle ist bereits vorbereitet.
Wichtige Einschränkung: Retention-Kennzahlen fremder Kanäle sind über die öffentliche YouTube-API nicht verfügbar. Der Agent weist diese Felder deshalb konsequent als „nicht verfügbar“ aus, statt sie aus Aufrufen oder Likes zu schätzen. Belastbare Retention-Aussagen sind erst mit eigenen Analytics-Daten möglich.
